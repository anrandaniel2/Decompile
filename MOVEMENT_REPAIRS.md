# Movement repairs (optional, not exact deobfuscation)

Use [`cheesy.movement-repaired.luau`](cheesy.movement-repaired.luau) to try the targeted movement/character fixes. [`cheesy.deobfuscated.luau`](cheesy.deobfuscated.luau) remains the faithful reconstruction of the attached script. The repaired variant deliberately changes the original behavior, so it is **not** a claim of exact equivalence or a verified working Roblox build.

## What the attachment actually contains

The four entries initialized to `nil` in `Functions` (`FirePrompt`, `GetLibraryCode`, `HasItem`, `HandleHidingTransparency`) are assigned real implementations later in the *original* script, at readable lines 4865–4959. A tree-sitter audit of both the attachment and reconstruction found **zero empty function bodies**. There are two empty `if` blocks, also present in the original, but no evidence that the reconstruction replaced feature implementations with stubs. Some features do require unavailable executor APIs, the current DOORS game structure, or downloaded UI/ESP libraries; a successful compile or a visible toggle does not prove those paths work.

## Intentional fixes in the repaired variant

- **Character physics / Remove Acceleration:** `saveCharacterPhysics()` originally dereferences `HumanoidRootPart.CustomPhysicalProperties.Friction` without checking whether `CustomPhysicalProperties` is `nil` (the ordinary material-default case). Use `CurrentPhysicalProperties` as a fallback and avoid writing a nonexistent custom physics value. This prevents initialization from aborting at that point when the root has no custom material.
- **Noclip / Phase:** Turning either feature off originally sets *every* collected part's `CanCollide` to `true`, including parts that were non-colliding to begin with. Save each part's prior value, restore it only after both toggles are off, and track new parts while Noclip is active. Cleanup on unload forces restoration.
- **Twerk animation:** The original starts a local animation track but the off callback tests a different, never-assigned `TwerkTrack`; keep the active track and stop/clear it when disabled.

These defects also exist in the supplied obfuscated script; they were **not introduced by renaming**. They are concrete fixes, not invented implementations for unavailable features. The patched file is generated by `python3 tools/patch_movement.py` from the checked-in *formatted* reconstruction. If you regenerate the base file, format it before patching; otherwise the patcher intentionally fails rather than matching the wrong code.

`tools/validate_movement.py --luau /path/to/luau` compiles the patched file and runs only isolated functions with fake parts/signals. It checks nil default physics, animation on/off, collision restoration, dynamically added parts, and Noclip/Phase overlap. CI also checks that the patched file can be reproduced. **Neither test executes the whole script or Roblox/remote libraries.**
